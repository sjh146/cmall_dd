# cmall_dd — 퀀트 트레이더 커뮤니티 전환 비전 (2026-08-15)

> 목표: "AI 분석 상품 파는 쇼핑몰" → **알고리즘 퀀트 트레이딩 트레이더들의
> 기술 공유 · 소통 · 학습 플랫폼**. 상품 판매는 수익 수단이고, 커뮤니티가 본체.

---

## 1. 왜 바꾸는가

- 현재 cmall_dd는 상품 3종(분석/스크리너/팩터)을 파는 쇼핑몰에 가까움
- 실제 사용자 가치 = **"퀀트 전략을 만들고 검증하고 서로 배우는 장"**
- 분석 리포트는 커뮤니티 활동의 결과물(entry point)이어야 함 — 목적이 아니라 수단

## 2. 커뮤니티 방향 (3축)

| 축 | 내용 | 초기 기능 |
|---|---|---|
| **공유** | 전략/코드/백테스트 결과 공유 | 전략 게시판, 리포트 공개/공유 버튼, 백테스트 결과 첨부 |
| **소통** | 트레이더 간 질문/피드백 | 댓글, 전략 토론 스레드, 종목 분석 요청 게시판 |
| **학습** | 초보 → 고수 성장 경로 | 전략 지식 문서(위키), 용어집, 강환국 전략 해설, 샘플 코드 |

## 3. 단계 (기존 인프라 활용)

| 단계 | 내용 | 기존 자산 |
|---|---|---|
| 1 (지금) | 공지 재작성(사람 톤) + 올액세스 구독 | ✅ 완료 — notice, 구독 컨트랙트 |
| 2 | 상품 상세/리포트에 **공유 버튼** + 전략 게시판 (간단 게시판 — notice/lecture 테이블 재활용) | notices/lectures 테이블 |
| 3 | 리포트 결과 페이지 → **커뮤니티 링크** (이 종목 보는 사람들, 비슷한 전략) | analyist_dd reports |
| 4 | 정기 콘텐츠: 주간 스크리너 해설, 전략 챌린지 (백테스트 대회) | job-runner + cron |
| 5 | 위키/학습 허브 (전략 용어, 샘플 전략 코드) | static 마크다운 |

## 4. 구독과의 연결 (수익 모델)

- **월 $5 올액세스 구독** = 전 서비스 무제한 (구현 완료 — SubscriptionManager)
- 커뮤니티 활성화 → 구독 전환율 ↑ (전략 공유가 구독 동기)
- 톤/문서 원칙: **AI 티 제거** — 이모티콘 남용 금지, 사람이 쓴 자연스러운 문체

## 5. 원칙

- **무료 콘텐츠는 풍부하게, 유료는 결과물에만** (게시판 읽기 무료, 리포트 생성은 결제/구독)
- 데이터/보안: 공유되는 전략 코드에 실거래 키 금지 (보안 검토 게이트)
- 커뮤니티 글은 사용자 생성 — 운영팀(본인)이 직접 톤 가이드라인 제시
